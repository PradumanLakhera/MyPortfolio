# Praduman Lakhera — Developer Portfolio

A responsive portfolio built with React, Vite, Tailwind CSS, Motion, and Lucide. It features selected projects, skills, a learning journey, and configurable contact links.

## Run locally

```bash
npm install
npm run dev
```

Create `.env.local` from `.env.example` to configure your public contact links. Restart Vite after changing environment variables.

## Build

```bash
npm run build
npm run preview
```

Only add public profile URLs and a public contact email to the Vite environment. These values are included in the client side website.
